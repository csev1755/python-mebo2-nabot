============
Installation
============

#. **Create a Virtual Environment**

   .. code-block:: sh

      python3 -m venv venv

#. **Activate the Virtual Environment**

   - Windows

     .. code-block:: bat

        venv\Scripts\activate

   - macOS / Linux

     .. code-block:: sh

        source venv/bin/activate

#. **Install Module**

   .. code-block:: sh

      pip install .
